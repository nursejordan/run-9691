# Memory Pocket
Calm, readable, low-distraction personal memory workspace. Warm ivory #f8f7f3 canvas, white writing surface, forest #2c594a primary, muted sage #eaf0e9 active states, charcoal #29342d text and #657069 secondary. Typography: Poppins for navigation/body, Georgia for expressive editorial headings. Left desktop rail 236px; content centered at max 1050px. On mobile use bottom navigation. 8px spacing system, generous 32–48px sectional gaps, softly rounded writing area, thin borders, no ornamental gradients. Icons: lucide line icons. Three core destinations: Remember, Find, Today. Capture has one primary action and no required metadata. Recent notes use simple separated rows. Neutral empty states and explicit errors. Short summaries on demand; source-linked retrieval. Accessible focus rings, reduced-motion support, 44px touch targets. Auth in a matching modal with sign-in/create account tabs. Preview mode clearly labeled, no private-note access without authentication.
